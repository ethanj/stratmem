# The Ask & Roadmap

==Pre-seed funding to transition from iOS BLE-mesh prototype → ATAK plugin + long-range radio production system, and to secure a DARPA Program of Record.==

## Use of funds (pre-seed)
- **ATAK port** — TacNet as an ATAK plugin for Android tablets (vehicle-mounted and commander).
- **Long-range radio bring-up** — LoRa + SDR reference nodes for dismounted transport, replacing BLE.
- **STTR Phase I prep** — solicitation response, regulatory paperwork, Cornell co-PI structure.
- **Two engineering hires** — one **embedded / RF** (long-range radio, ATAK integration), one **on-device ML**.
- **Field-test budget** — ATAK tablets, long-range radio hardware sets, range testing, EW resilience trials with MN Guard.

## Roadmap

### Phase 0 — iOS prototype (now)
- Native iOS app, Cactus + Gemma 4 E4B, BLE mesh (prototype transport only), drag-and-drop tree.
- Demo video, landing site, hackathon validation.
- Repo: `voice-agents-hack/OLD CODE`.

### Phase 1 — STTR Phase I (next 6–12 months)
- DARPA-PS-26-09 (STO) submission with Cornell as research partner.
- Feasibility study: ATAK port + long-range radio transport for dismounted nodes.

### Phase 2 — STTR Phase II + multi-transport (12–36 months)
- Production-grade long-range radio transport (LoRa / SDR / FHSS).
- Full ATAK integration for vehicle-mounted and commander nodes.
- NPU-optimized SLM inference (custom edge chips or partner reference designs).
- Civilian dual-use pilots (SAR, mining).

### Phase 3 — Program of Record
- Sole-source DoD contracts under Phase III pathway.
- Land-and-expand into adjacent commands, allied militaries (Five Eyes).

## Milestones the pre-seed buys
- ATAK plugin alpha + long-range radio prototype shipping on hardware.
- One signed STTR Phase I award.
- One NDA'd warfighter pilot (MN Guard platoon/company level).
- A defensible IP filing on **semantic-compression-over-mesh**.

## Investor profile
- Defense-tech specialists (e.g., A*, Lux, Founders Fund's defense practice, 8VC, Shield Capital, Razor's Edge).
- Strategic LPs with DoD relationships.
- Angels with prior STTR / DIU operator credibility.
